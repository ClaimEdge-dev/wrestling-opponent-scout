## HOW USA WRESTLING (USAW) PIN NUMBERS WORK

### What is a USAW PIN?
A **USAW PIN** is a unique 10-digit number assigned to every wrestler when they register for USA Wrestling membership. It serves as their permanent identifier across all USAW-sanctioned events.

| Function | Description |
|----------|-------------|
| **Tournament Entry** | Required for any USAW-sanctioned tournament |
| **Membership Verification** | Proves current membership + insurance |
| **Results Tracking** | Links all results to permanent profile |
| **Weight Certification** | Required for state-level programs |
| **Coach Verification** | Coaches verify roster eligibility |

### Card Types

| Type | Color | Cost | Coverage |
|------|-------|------|----------|
| Full Athlete | Red/Blue | ~$50/yr | All events + insurance |
| Limited Folkstyle | Orange | ~$25/yr | Folkstyle only |
| Coach/Medical | Green | ~$50/yr | Coach cert |
