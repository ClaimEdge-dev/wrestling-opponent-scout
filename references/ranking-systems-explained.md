# Wrestling Ranking Systems Explained

## 1. USAW PIN (Performance Index Number)

USAW's official points-based rating system.

### How Points Are Earned
| Component | Description |
|-----------|-------------|
| Tournament Placement | 1st = most points, 10th = minimum |
| Tournament Level | National > Regional > State > Local |
| Field Size | 64-person bracket > 8-person bracket |
| Style | Freestyle, Greco-Roman, Folkstyle tracked separately |
| Recency | Recent results weighted heavier |

### PIN Scale
| PIN Range | Level |
|-----------|-------|
| 1300+ | ELITE (National champion/finalist) |
| 1200-1299 | NATIONAL (Top-8 at nationals) |
| 1100-1199 | STATE (State placer) |
| 1000-1099 | REGIONAL |
| 900-999 | LOCAL |
| <900 | BEGINNER |

**Find PINs:** themat.com → Search wrestler name

## 2. Trackwrestling Rank Value

Trackwrestling's 0.00-1.00 scoring system.

### How It Works
> "Based on 4 tournament levels: local, state, regional, national. Each category gets an average percentile of how the wrestler finished in the bracket. Placing 4th in 8-wrestler bracket = 8th in 16-wrestler bracket. Combined and weighted for final number."

### Scale
| Rank Value | Classification |
|------------|----------------|
| **0.75+** | **"Significant Wrestler"** |
| 0.60-0.74 | Strong state-level |
| 0.45-0.59 | Regional competitor |
| 0.30-0.44 | Local tournament |
| <0.30 | Limited experience |

**Also:** 1-5 stars based on record + rank value + significant wins

## 3. FloWrestling Rankings

Gold standard for national rankings.

### Factors
| Factor | Weight |
|--------|--------|
| Tournament Results | 40% |
| Head-to-Head | 25% |
| Video Analysis | 20% |
| Consistency | 15% |

### Tiers
- **Flo Ranked (Top 10-20):** Nationally recognized
- **Flo Mentioned:** Event coverage, not ranked
- **Flo Profile Only:** Profile exists, no editorial
