# Scouting Workflow

## Trackwrestling
1. Navigate to trackwrestling.com
2. Search wrestler by name + state
3. Extract: Record, placements, tournament history
4. Note: Requires login for detailed data

## FloWrestling
1. Navigate to flowrestling.org
2. Search wrestler profile
3. Extract: Rankings, videos, articles
4. Note: Subscription required for full access

## NUWAY Combat
1. Navigate to nuwaycombat.com
2. Search event results
3. Extract: Match results, brackets

## USA Wrestling
1. Navigate to themat.com
2. Search membership database
3. Extract: Membership ID, events entered

## State Federations
- IKWF (Illinois): ikwf.org
- ISWA (Indiana): indianausawrestling.com
- MHWA (Michigan): mhwrestling.org
- Ohio: ohwrestling.net
